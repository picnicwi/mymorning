สวัสดีตอนเช้าครับ ยินดีต้อนรับสู่ MorningInsight พอดแคสต์สรุปข่าว AI และเทคโนโลยี ประจำวันอังคารที่สอง มิถุนายน สองพันห้าร้อยหกสิบเก้า วันนี้เรามีข่าวทั้งหมดสิบหก เรื่องจากหกหัวข้อหลัก ไปติดตามกันเลยครับ


หัวข้อที่หนึ่ง AI และ Generative AI

เริ่มกันด้วยข่าวใหญ่ครับ รายงาน State of Global AI Diffusion ของ Microsoft เผยว่าอัตราการใช้งาน AI ทั่วโลกในหมู่ประชากรวัยทำงานเพิ่มขึ้นเป็นร้อยละสิบเจ็ดจุดแปดในไตรมาสแรกของปีนี้ จากเดิมร้อยละสิบหกจุดสามเมื่อไตรมาสก่อน ตัวเลขนี้สะท้อนให้เห็นว่า AI กำลังกลายเป็นเครื่องมือประจำวันของคนทำงานทั่วโลกอย่างรวดเร็ว

ต่อมา MIT Technology Review ได้เผยแพร่รายชื่อสิบเทรนด์ AI ที่สำคัญที่สุดในปีสองพันยี่สิบหก ครอบคลุมตั้งแต่ Agentic AI ไปจนถึง Multimodal Models และบทบาทของ AI ในงานวิทยาศาสตร์ รายการนี้ถือเป็นแผนที่นำทางสำหรับทุกคนที่อยู่ในวงการเทคโนโลยีเลยครับ

และข่าวที่น่าเป็นห่วงมากในหัวข้อนี้คือ Deepfake เริ่มแพร่ระบาดในระดับที่น่าตกใจ ความก้าวหน้าของ Generative AI ทำให้การสร้าง Synthetic Media แบบ Nonconsensual กลายเป็นเรื่องง่ายมาก นักวิเคราะห์เตือนว่า AI Phishing และ Social Engineering กำลังซับซ้อนและแพร่หลายมากขึ้นเรื่อยๆ ภัยคุกคามที่เคยเป็นแค่ทฤษฎีได้กลายเป็นความจริงแล้วครับ


หัวข้อที่สอง เทรนด์อุตสาหกรรมเทคโนโลยี

Google เพิ่งเปิดตัว Gemini Enterprise Agent Platform ในงาน Cloud Next 26 พร้อมกับ TPU รุ่นที่แปด แพลตฟอร์มนี้ช่วยให้องค์กรสร้าง ปรับใช้ และควบคุม AI Agents อัตโนมัติสำหรับงานที่ซับซ้อนหลายขั้นตอนได้ ถือเป็นก้าวสำคัญที่ Google ผลักดันให้ AI ระดับองค์กรเข้าถึงได้ง่ายขึ้น

Dell Technologies เปิดเผยว่า AI Factory ที่พัฒนาร่วมกับ NVIDIA มีลูกค้าองค์กรแล้วห้าพันรายทั่วโลก เพิ่มขึ้นหนึ่งพันรายในไตรมาสเดียว ตัวเลขนี้แสดงให้เห็นถึงความต้องการโครงสร้างพื้นฐาน AI ระดับองค์กรที่พุ่งสูงขึ้นอย่างต่อเนื่อง

นอกจากนี้ยังมีรายงานน่าสนใจเกี่ยวกับการผสานรวม AI เข้ากับ Platform Engineering ครับ บริษัทอย่าง Anthropic และ GitHub กำลังฝัง AI เข้าไปในกระบวนการด้านโครงสร้างพื้นฐานโดยตรง เส้นแบ่งระหว่าง Infrastructure และ Intelligent Automation กำลังเลือนลางลงเรื่อยๆ


หัวข้อที่สาม ธนาคารและบริการทางการเงิน

นี่คือหัวข้อที่ผู้ที่อยู่ในวงการการเงินต้องฟังครับ ผลสำรวจล่าสุดพบว่า ร้อยละเจ็ดสิบแปดของธนาคารทั่วโลกได้นำ Generative AI มาใช้งานในแบบ Tactical แล้วในปีนี้ เพิ่มขึ้นจากเพียงร้อยละแปดในปีสองพันยี่สิบสี่ และร้อยละสี่สิบเจ็ดได้ Roll Out แอปพลิเคชัน GenAI ในการปฏิบัติการจริงแล้ว

ยิ่งน่าตื่นเต้นมากขึ้นไปอีกครับ งานวิจัยใหม่ชี้ว่า Agentic AI ในภาคธนาคารมีศักยภาพที่จะเพิ่มประสิทธิภาพการดำเนินงานได้ถึงร้อยละยี่สิบ แม้ว่าปัจจุบันมีธนาคารเพียงร้อยละสามสิบเอ็ดเท่านั้นที่เริ่มนำ Agentic AI มาใช้งานจริงแล้ว ยังมีโอกาสอีกมากที่รออยู่

และ McKinsey ประเมินว่า Generative AI มีศักยภาพสร้างมูลค่าให้กับธุรกิจธนาคารได้สองร้อยถึงสามร้อยสี่สิบพันล้านดอลลาร์ต่อปี หรือคิดเป็นร้อยละเก้าถึงสิบห้าของกำไรจากการดำเนินงาน ตัวเลขนี้บอกเราว่า AI ไม่ใช่แค่เครื่องมือประหยัดต้นทุน แต่เป็นโอกาสทางธุรกิจขนาดใหญ่มากครับ


หัวข้อที่สี่ Data Platforms

งาน FabCon และ SQLCon สองพันยี่สิบหกเป็นงานสำคัญมากสำหรับคนทำงานด้านข้อมูลครับ Microsoft ประกาศรวม Database Portfolio และ Microsoft Fabric เข้าเป็นแพลตฟอร์มข้อมูลเดียว มีการเปิดตัว OneLake และ Copilot สำหรับ SQL Server ซึ่งช่วยให้การจัดการข้อมูลระดับองค์กรง่ายขึ้นมาก

Azure Databricks ประกาศ General Availability ของ Lakebase ซึ่งเป็น Database ที่ออกแบบมาเพื่อ AI Agents โดยเฉพาะ พร้อมกับ Genie Code สำหรับ Agentic Data Engineering และ Lakeflow Connect Free Tier นี่คือสัญญาณว่าโลกของข้อมูลกำลังปรับตัวเพื่อรองรับ AI Agents อย่างจริงจัง

ในฝั่ง Microsoft เองก็ยังมีข่าวสำคัญครับ Azure AI Foundry ได้รีแบรนด์เป็น Microsoft Foundry ตั้งแต่มกราคมที่ผ่านมา สัญญาณนี้บ่งบอกว่า AI Agents กลายเป็น First-Class Citizens ในระบบนิเวศของ Microsoft อย่างเป็นทางการแล้ว


หัวข้อที่ห้า Microsoft AI

งาน Microsoft Build สองพันยี่สิบหกมีไฮไลต์สำคัญคือการขยาย Azure AI Platform และ Multi-Agent Orchestration ครับ มีการเปิดตัวโมเดล AI ใหม่อย่าง DeepSeek V4 Flash และ Phi-4 และยังมี Track สำคัญเกี่ยวกับ Agents and Apps, GitHub Developer Productivity, และ Microsoft Fabric

Microsoft กำลังวางตำแหน่งตัวเองอย่างชัดเจนว่าจะเป็นแพลตฟอร์มหลักสำหรับ Enterprise AI ในยุคที่ Agents กลายเป็นศูนย์กลางของทุกอย่าง ถ้าองค์กรไหนกำลังวางแผน AI Strategy ในอีกสองถึงสามปีข้างหน้า สิ่งที่ Microsoft ประกาศในงาน Build ต้องเป็นส่วนหนึ่งของการพิจารณาอย่างแน่นอนครับ


หัวข้อที่หก AI และ Cybersecurity

ปิดท้ายด้วยข่าวที่ต้องให้ความสนใจเป็นพิเศษครับ รายงานล่าสุดพบว่าร้อยละเก้าสิบเจ็ดขององค์กรทั่วโลกพบปัญหาด้านความปลอดภัยที่เกี่ยวข้องกับ GenAI ในปีนี้ โดยเฉลี่ยแต่ละองค์กรเจอเหตุการณ์ละเมิดนโยบาย GenAI ถึงสองร้อยยี่สิบสามครั้งต่อเดือน ซึ่งเพิ่มขึ้นเป็นสองเท่าจากปีก่อน

OWASP ได้อัปเดต LLM Top 10 สำหรับปีนี้ โดยระบุว่า Prompt Injection และ RAG Poisoning เป็นภัยคุกคามที่อันตรายที่สุดสำหรับระบบ AI บางเทคนิค Prompt Injection มีอัตราความสำเร็จในการโจมตีสูงถึงร้อยละแปดสิบแปด นี่เป็นตัวเลขที่น่ากังวลมากสำหรับทุกองค์กรที่นำ LLM มาใช้งาน

และ Google Cloud ออกรายงานพบว่าผู้ไม่หวังดีกำลังใช้ AI ช่วยในการค้นหา Vulnerability และเปิดการโจมตีในระยะแรก AI ไม่ได้อยู่แค่ฝั่งผู้ป้องกันแล้ว แต่กำลังถูกนำไปใช้เป็นอาวุธในมือของ Adversaries ด้วย


ห้าสิ่งที่ต้องจับตามองวันนี้

หนึ่ง อัตราการใช้ AI ในวัยทำงานทั่วโลกแตะร้อยละสิบเจ็ดจุดแปดแล้ว เทรนด์นี้จะเร่งตัวต่อเนื่องตลอดปี

สอง ธนาคารและสถาบันการเงินกำลังอยู่ในจุดเปลี่ยนครั้งใหญ่ GenAI ไม่ใช่ทดลองแล้ว แต่กลายเป็น Standard ของอุตสาหกรรม

สาม Microsoft กำลังรวม Platform ทุกอย่างเข้าด้วยกัน ถ้าองค์กรคุณใช้ Microsoft Stack อยู่แล้ว กลยุทธ์ AI ของคุณจะถูกพลิกโฉมอีกครั้ง

สี่ Deepfake และ AI Phishing ถึงจุดที่อันตรายอย่างแท้จริงแล้ว ทุกองค์กรต้องเพิ่ม Security Awareness ในเรื่องนี้โดยเร่งด่วน

ห้า Agentic AI กำลังจะเปลี่ยนโฉมทั้ง Infrastructure และ Financial Operations ในเวลาเดียวกัน องค์กรที่เตรียมตัวก่อนจะได้เปรียบอย่างมาก
