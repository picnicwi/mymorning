สวัสดีตอนเช้าครับ ยินดีต้อนรับสู่ MorningInsight พอดแคสต์สรุปข่าว AI และเทคโนโลยี ประจำวันพฤหัสบดีที่ ยี่สิบเอ็ด พฤษภาคม สองพันห้าร้อยหกสิบเก้า ผมจะพาทุกท่านทบทวนข่าวสำคัญจากวงการ AI Big Data และเทคโนโลยีในแวดวงการเงิน รวมทั้งหมดสิบแปดเรื่องใน หกหมวดใหญ่วันนี้ครับ เตรียมกาแฟให้พร้อม แล้วมาเริ่มกันเลยครับ


หมวดแรก AI และ Generative AI

เริ่มต้นด้วยข่าวใหญ่จาก Apple ครับ บริษัทกำลังเตรียมเปิดให้ผู้ใช้เลือก AI provider จากภายนอกได้ใน iOS ยี่สิบเจ็ด, iPadOS ยี่สิบเจ็ด และ macOS ยี่สิบเจ็ด ไม่ว่าจะเป็น Google หรือ Anthropic ก็สามารถมาขับเคลื่อน Apple Intelligence แทนที่ระบบเดิมได้ นี่ถือเป็นการเปลี่ยนแปลงครั้งใหญ่มากครับ เพราะ Apple มักล็อกผู้ใช้ไว้ในระบบนิเวศของตัวเองเสมอมา ถ้าสำเร็จ อาจสร้างมาตรฐานใหม่ให้อุตสาหกรรมในเรื่องการพกพา AI ข้ามแพลตฟอร์มครับ

เรื่องที่สองครับ Google เปิดตัว Gemini สาม จุด ห้า Flash สู่การใช้งานแบบ General Availability แล้ว โดยรันเร็วกว่าโมเดลเทียบเท่าถึงสี่เท่า ในขณะที่ยังคงความสามารถเชิงเหตุผลในระดับ frontier ไว้ได้ครบถ้วน เป้าหมายชัดเจนคือ enterprise workload ที่ต้องการ inference แบบ low-latency ครับ บวกกับ TPU รุ่นที่แปดที่เพิ่งเปิดตัวใน Cloud Next ยี่สิบหก นี่คือการผลักดันอย่างจริงจังของ Google เพื่อครองโครงสร้างพื้นฐาน AI ในยุค agentic ครับ

ปิดหมวดแรกด้วยรายงานจาก MIT Technology Review ครับ นักวิเคราะห์เริ่มพูดถึงการเปลี่ยนแปลงจาก AI agent เดี่ยวสู่ทีม agent ที่ทำงานร่วมกันแบบประสานงาน ซึ่งสามารถจัดการงานที่ซับซ้อนกว่าเดิมได้มาก รายงาน AI Trend ปีนี้จัด multi-agent orchestration เป็นหนึ่งในสิบเรื่องที่สำคัญที่สุด และเราเริ่มเห็นการ deploy จริงในสาขา logistics, legal research และ financial analysis แล้วครับ


หมวดที่สอง เทรนด์เทคโนโลยี

เปิดด้วย Google Cloud Next ยี่สิบหกครับ Google เปิดตัว Gemini Enterprise Agent Platform พร้อม TPU รุ่นที่แปด โดยเปลี่ยนจุดยืนจาก model-centric มาเป็น agent-centric อย่างสมบูรณ์ แพลตฟอร์มนี้ให้องค์กรเชื่อมต่อข้อมูล แอปพลิเคชัน และ workflow ผ่าน agent ที่ทำงานแทนธุรกิจได้ มีบริษัทใน Fortune ห้าร้อยจากภาคการผลิต โลจิสติกส์ และการเงิน ประกาศ deploy ใช้งานจริงแล้วครับ

เรื่องที่สองน่าสนใจมากครับ OpenAI ประกาศว่าลูกค้า enterprise ตอนนี้คิดเป็นมากกว่าสี่สิบเปอร์เซ็นต์ของรายได้รวม และกำลังเดินหน้าสู่จุดที่จะเท่ากับฝั่ง consumer ภายในสิ้นปีนี้ การเติบโตมาจาก ChatGPT Enterprise, API และการ deploy เฉพาะอุตสาหกรรมใน finance, healthcare และ legal ครับ ตัวเลขนี้ยืนยันชัดเจนว่า AI กำลังกลายเป็นโครงสร้างพื้นฐานธุรกิจ ไม่ใช่แค่ tool ทดลองใช้อีกต่อไปครับ

ปิดหมวดสองด้วย NVIDIA ครับ ในงาน GTC สองพันยี่สิบหก NVIDIA เปิดตัว Agent Toolkit แบบ open-source พร้อม architecture แบบ AI-Q hybrid ที่ลดต้นทุน query ลงกว่าห้าสิบเปอร์เซ็นต์ เครื่องมือนี้กำลังถูกประเมินโดยบริษัทในภาค manufacturing, financial services และ retail การที่ NVIDIA ปล่อยเป็น open-source ช่วยลดกำแพงให้องค์กรขนาดกลางเข้ามา deploy agent ได้ง่ายขึ้นมากครับ


หมวดที่สาม Banking และ Financial Services

ข่าวใหญ่จาก IBM ครับ รายงาน Global Banking Outlook ปีนี้เผยว่าสถาบันการเงินถึงเจ็ดสิบแปดเปอร์เซ็นต์ได้นำ generative AI ไปใช้แล้ว เพิ่มขึ้นอย่างก้าวกระโดดจากแค่แปดเปอร์เซ็นต์เมื่อสองปีที่แล้ว McKinsey ประเมินว่าเทคโนโลยีนี้อาจสร้างมูลค่าให้ภาคธนาคารถึงสองร้อยถึงสามร้อยสี่สิบพันล้านดอลลาร์ต่อปี หรือคิดเป็นเก้าถึงสิบห้าเปอร์เซ็นต์ของกำไรจากการดำเนินงาน ตัวเลขนี้บอกชัดว่า GenAI ไม่ใช่ทางเลือกแล้ว แต่เป็นความจำเป็นในการแข่งขันครับ

เรื่องต่อมาเกี่ยวกับ agentic AI ครับ แม้ว่าเจ็ดสิบเจ็ดเปอร์เซ็นต์ของธนาคารได้เริ่มเปิดตัวแอป generative AI แล้ว แต่มีแค่สามสิบเอ็ดเปอร์เซ็นต์เท่านั้นที่ก้าวไปสู่ agentic AI จริงๆ Agentic AI คือระบบที่ตัดสินใจเองได้หลายขั้นตอน และถูกมองว่าเป็น layer ถัดไปสำหรับการสร้างรายได้ ขณะนี้ front-office ที่ใช้ AI อยู่รายงานผลิตภาพเพิ่มขึ้นเฉลี่ยยี่สิบเจ็ดถึงสามสิบห้าเปอร์เซ็นต์ครับ ช่องว่างระหว่าง GenAI และ agentic AI คือโอกาสสำคัญของสถาบันที่กล้าก้าวก่อนครับ

ปิดหมวดสามด้วยการสำรวจด้านความเสี่ยงครับ ผู้นำด้าน compliance และ risk ในธนาคารถึงแปดสิบสองเปอร์เซ็นต์วางแผนเพิ่มการลงทุนด้าน AI มากกว่ายี่สิบห้าเปอร์เซ็นต์ในสองถึงสามปีข้างหน้า แรงผลักมาจากความต้องการด้านกฎระเบียบ การตรวจจับการฉ้อโกง และการ automate กระบวนการ KYC สถาบันที่ลงทุนใน AI เห็น ROI เป็นบวกภายในสิบแปดเดือนถึงเจ็ดสิบแปดเปอร์เซ็นต์ครับ


หมวดที่สี่ Data Platforms

Microsoft และ Databricks ประกาศความร่วมมือครั้งใหญ่ในงาน FabCon ครับ ขณะนี้ Databricks Unity Catalog อ่านข้อมูลจาก OneLake ของ Microsoft Fabric ได้โดยตรงแล้ว และกำลังเพิ่ม write access เร็วๆ นี้ การ integrate แบบ bidirectional นี้ช่วยลดปัญหา data duplication สำหรับองค์กรที่ใช้ทั้งสองแพลตฟอร์มควบคู่กัน ซึ่งในอดีตถือว่าเป็นคู่แข่งกัน นี่คือสัญญาณว่าสงครามแพลตฟอร์มกำลังเปลี่ยนเป็นความร่วมมือครับ

เรื่องที่สองครับ Azure Databricks เปิดตัว Lakebase ซึ่งเป็น managed serverless Postgres ที่ built-in อยู่ใน lakehouse โดยตรง ออกแบบมาเพื่อรองรับ AI agent ที่ต้องการระบบ transactional แบบ real-time โดยเฉพาะ ไม่ต้องใช้ database แยกต่างหากอีกต่อไป เพราะรวม OLTP และ OLAP ไว้ด้วยกันในที่เดียว Microsoft ยังซื้อกิจการ Osmos ซึ่งเป็นแพลตฟอร์ม data engineering ที่ขับเคลื่อนด้วย AI มาเสริมใน Fabric ด้วยครับ

ปิดหมวดสี่ด้วยภาพรวมจาก FabCon สองพันยี่สิบหกครับ Microsoft ส่งสัญญาณชัดเจนว่ายุคของ data tool แบบแยกส่วนกำลังจะสิ้นสุดลง Microsoft Fabric เดินหน้าเพิ่มความสามารถใหม่ทั้งใน OneLake, Real-Time Intelligence และ AI-native data pipeline วิสัยทัศน์คือแพลตฟอร์มเดียวที่รวมทุกอย่างไว้ ถ้าองค์กรใหญ่ pivot มาใช้แนวทางนี้ จะส่งแรงกดดันอย่างมากต่อผู้ให้บริการ point solution รายเล็กในตลาดครับ


หมวดที่ห้า Microsoft และ AI

Microsoft ได้ rebranding Azure AI Foundry เป็น Microsoft Foundry แล้วครับ และที่สำคัญคือโมเดลของ Anthropic ซึ่งก็คือ Claude เข้ามาอยู่ในแพลตฟอร์มนี้แล้ว ทำให้นักพัฒนา enterprise เลือกใช้ frontier AI ได้หลายยี่ห้อโดยไม่ต้องออกจาก compliance framework ของ Microsoft การ rebranding นี้สะท้อนว่า Microsoft ต้องการให้ Foundry เป็น marketplace สำหรับ AI model มากกว่าเป็นแค่เครื่องมือของ Azure ครับ

ตามมาด้วย DeepSeek ครับ Microsoft ประกาศให้ DeepSeek V สี่ Flash และ V สี่ Pro เข้าร่วมใน Microsoft Foundry แล้ว โดย Flash เหมาะกับงาน low-latency ราคาประหยัด ส่วน Pro รองรับงานที่ต้องการการ reasoning ที่ซับซ้อน การมี open-weight model คุณภาพสูงใน cloud ที่ปลอดภัยและ compliant เพิ่มแรงกดดันให้ผู้ให้บริการโมเดล proprietary ต้องแข่งทั้งด้านราคาและประสิทธิภาพครับ

ปิดหมวดห้าด้วย Microsoft Copilot Agent Mode ครับ จาก Build สองพันยี่สิบหก ตอนนี้ Agent Mode ที่ให้ AI ทำงานแบบหลายขั้นตอนอัตโนมัติ กำลังขยายไปครอบคลุม Word, Excel, PowerPoint, Outlook และ OneNote แล้ว Microsoft ยังเปิดตัว Foundry IQ และ Fabric IQ สำหรับเชื่อมแหล่งข้อมูลต่างๆ เข้ากับ Copilot รวมถึง Azure HorizonDB ที่มี vector indexing ในตัว ถ้า agentic AI ฝังตัวในเครื่องมือที่ใช้ทุกวันได้สำเร็จ มันจะกลายเป็นความคาดหวังปกติในที่ทำงานโดยไม่ต้องบังคับครับ


หมวดที่หก Cybersecurity

เปิดด้วยรายงานความเสี่ยงด้าน security ของ LLM ครับ OWASP ได้อัปเดต LLM Top สิบ ให้ครอบคลุมภัยใหม่ที่กำลังโตอย่างรวดเร็ว ได้แก่ prompt injection, การใช้งาน agent ในทางที่ผิด, การรั่วไหลของข้อมูลใน RAG pipeline และ Shadow AI ที่เป็นเครื่องมือ AI ที่ไม่ได้รับการอนุมัติจากองค์กร งานวิจัยพบว่าเทคนิคโจมตีบางอย่างมีอัตราสำเร็จสูงถึงแปดสิบแปดเปอร์เซ็นต์ครับ ทีม security จำเป็นต้องพัฒนา red-teaming และ monitoring ที่เฉพาะสำหรับ AI โดยด่วนครับ

เรื่องต่อมาน่ากังวลมากครับ ผู้ไม่หวังดีตอนนี้ใช้ generative AI เพื่อ automate วงจรการโจมตีทั้งหมด ตั้งแต่ค้นหาช่องโหว่ ผลิต exploit จนถึง deliver malware Google Cloud Threat Intelligence รายงานว่า LLM ถูกใช้เพื่อเลียนแบบพฤติกรรมผู้ใช้จริง ปรับปรุง social engineering และเร่งขั้นตอนบุกรุกทางเทคนิค สิ่งที่อันตรายที่สุดคือช่วงเวลาระหว่างที่ช่องโหว่ถูกเปิดเผยกับที่ถูกโจมตีจะสั้นลงมากครับ ต้องแพทช์ให้เร็วกว่าเดิมครับ

ปิดท้ายหมวดสุดท้ายด้วยภัยคุกคามจาก supply chain ครับ Threat actor กำลังใช้ AI สแกน open-source repository และสร้าง patch ที่มีโค้ดอันตรายซ่อนอยู่ โดยเล็งเป้าไปที่ library สำหรับ LLM และ AI agent โดยเฉพาะ แม้ระบบ core ของ frontier model ยังไม่ถูกเจาะในช่วงต้นปีนี้ แต่จุดอ่อนอยู่ที่ supply chain, data poisoning และ prompt injection ใน multi-agent pipeline นักวิจัยจาก Arctiq ย้ำว่าตอนนี้ต้องวางกลยุทธ์ AI security ในระดับ board แล้วครับ


ห้าสิ่งที่ต้องจับตามองวันนี้

อย่างแรกคือ Apple เตรียมเปิด platform ให้เลือก AI provider ได้อย่างอิสระ นี่คือ watershed moment ที่อาจเปลี่ยน dynamic การแข่งขันในตลาด AI ทั้งหมดครับ

อย่างที่สองคือ ธนาคารเจ็ดสิบแปดเปอร์เซ็นต์ใช้ GenAI แล้ว แต่มีแค่สามสิบเอ็ดเปอร์เซ็นต์ที่ขยับไป agentic AI ช่องว่างนี้คือโอกาสทองสำหรับสถาบันที่พร้อมก้าวข้ามไปก่อนครับ

อย่างที่สามคือ Microsoft Foundry กำลังกลายเป็น marketplace ของ AI model ที่แท้จริง ด้วยการเพิ่ม Claude และ DeepSeek เข้ามา enterprise มีทางเลือกมากขึ้นโดยไม่ต้องยอมรับ lock-in ครับ

อย่างที่สี่คือ OneLake และ Databricks กำลัง integrate แบบ bidirectional ซึ่งถือเป็นข่าวดีมากสำหรับ data team ที่ต้องทำงานทั้งสองแพลตฟอร์มควบคู่กันอยู่ครับ

และอย่างสุดท้ายคือ ภัยคุกคาม AI security กำลังพัฒนาเร็วมาก ทั้ง prompt injection, supply chain attack และ LLM-enabled malware ไม่ใช่ proof-of-concept อีกต่อไปแล้วครับ ถึงเวลาจริงจังกับ AI security strategy โดยด่วนครับ
