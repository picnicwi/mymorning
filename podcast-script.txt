สวัสดีตอนเช้าครับ ยินดีต้อนรับสู่ MorningInsight พอดแคสต์สรุปข่าว AI และเทคโนโลยี ประจำวันอังคารที่ สามสิบ มิถุนายน สองพันห้าร้อยหกสิบเก้า วันนี้มีข่าวสำคัญจากหกหมวดหมู่ ทั้ง AI รุ่นใหม่ แนวโน้มอุตสาหกรรมเทค ธนาคารและการเงิน แพลตฟอร์มข้อมูล Microsoft AI และความปลอดภัยไซเบอร์ เริ่มกันเลยครับ


หมวดแรก AI และ Generative AI

เรื่องแรกที่น่าตื่นเต้นมากครับ OpenAI จับมือกับ Broadcom เปิดตัวชิป AI ตัวแรกของตัวเองในชื่อ Jalapeño เมื่อวันที่ยี่สิบสี่มิถุนายนที่ผ่านมา ผลการทดสอบในห้องแล็บเบื้องต้นบอกว่าชิปนี้ประหยัดต้นทุน inference ได้ประมาณห้าสิบเปอร์เซ็นต์เมื่อเทียบกับ GPU ของ Nvidia รุ่นปัจจุบัน แผนคือจะนำไปใช้ในดาต้าเซ็นเตอร์จริงภายในสิ้นปีนี้ และผลิตแบบเต็มสเกลในช่วงครึ่งแรกของปีสองพันยี่สิบแปด ถ้าทำได้จริงนี่คือการเปลี่ยนเกมครับ เพราะ OpenAI จะลดการพึ่งพา Nvidia ลงได้อย่างมาก

เรื่องที่สอง DeepSeek ประกาศทำให้การลดราคาเจ็ดสิบห้าเปอร์เซ็นต์ของโมเดล V4-Pro เป็นราคาถาวร ตอนนี้อยู่ที่ศูนย์จุดสี่สี่ดอลลาร์ต่อล้าน input token และศูนย์จุดแปดเจ็ดดอลลาร์ต่อล้าน output token ซึ่งถูกกว่า GPT-5.5 มากกว่าห้าเท่าในส่วน input และสิบเจ็ดเท่าในส่วน output สงครามราคา AI นี้กำลังกดดันผู้ให้บริการรายอื่นอย่างหนักครับ

เรื่องที่สาม Anthropic ออกมากล่าวหา Alibaba ว่าทำ API exchanges ปลอมกับ Claude มากถึงยี่สิบแปดจุดแปดล้านครั้ง ซึ่งเป็นเรื่องใหญ่มากในแง่ความตึงเครียดทางภูมิรัฐศาสตร์ด้าน AI และในช่วงเดียวกันนี้ นักวิจัยอาวุโสจาก Google Gemini สี่คนก็ย้ายมาร่วมงานกับ Anthropic ภายในหกวัน ทำให้สงครามแย่งชิงบุคลากร AI ยิ่งร้อนแรงขึ้นอีก

เรื่องที่สี่ Reasoning model อย่าง OpenAI o1 และ DeepSeek-R1 กลายเป็นเทรนด์หลักแล้วครับ ความสามารถมัลติโมดัลกลายเป็นมาตรฐานในโมเดลชั้นนำ และต้นทุนลดลงมากจนสามารถได้ประสิทธิภาพระดับ GPT-4 ในราคาที่ถูกกว่าเมื่อปีที่แล้วมากจนเทียบไม่ได้ สิ่งนี้หมายความว่าความได้เปรียบทางการแข่งขันในอนาคตไม่ได้อยู่ที่โมเดลแล้ว แต่อยู่ที่การ integration และข้อมูลครับ


หมวดที่สอง แนวโน้มอุตสาหกรรมเทค

Gartner พยากรณ์ว่าการลงทุนด้านซอฟต์แวร์ AI agent ในปีสองพันยี่สิบหกนี้จะแตะสองร้อยหกจุดห้าพันล้านดอลลาร์ เพิ่มขึ้นร้อยสามสิบเก้าเปอร์เซ็นต์จากแปดสิบหกจุดสี่พันล้านในปีที่แล้ว ตัวเลขนี้บอกชัดครับว่า agentic AI ไม่ใช่ทรงพักหรือเทรนด์วิจัยอีกต่อไปแล้ว มันคือโครงสร้างพื้นฐานระดับองค์กร

Microsoft ประกาศที่งาน Build 2026 ว่า Agent Mode จะเป็นค่าเริ่มต้นใน Office 365 Copilot แล้ว และฟีเจอร์ agentic หลายตัวอย่าง computer-using agents, การสื่อสาร agent-to-agent และ real-time voice agents ทั้งหมดย้ายจาก preview เป็น general availability แล้ว นี่หมายความว่าพนักงานออฟฟิศหลายร้อยล้านคนทั่วโลกจะเริ่มทำงานร่วมกับ AI agents โดยอัตโนมัติครับ

Google ก็ไม่น้อยหน้าครับ ที่งาน Cloud Next 26 Google เปิดตัว Gemini Enterprise Agent Platform พร้อม TPU รุ่นที่แปด ให้องค์กรสร้างและควบคุม AI agents สำหรับงานธุรกิจที่ซับซ้อนหลายขั้นตอน การแข่งขันระหว่าง Microsoft Copilot และ Google ใน enterprise AI infrastructure ยิ่งเข้มข้นขึ้นอีกแล้วครับ


หมวดที่สาม ธนาคารและการบริการทางการเงิน

IBM รายงานว่าเจ็ดสิบแปดเปอร์เซ็นต์ของธนาคารทั่วโลกนำ GenAI มาใช้ในเชิงกลยุทธ์แล้วในปีนี้ เพิ่มขึ้นสิบเท่าจากแปดเปอร์เซ็นต์ในปีสองพันยี่สิบสี่ แต่มีเพียงสามสิบเอ็ดเปอร์เซ็นต์เท่านั้นที่ก้าวข้ามไปถึง agentic AI จริงๆ ช่องว่างนี้คือโอกาสและความท้าทายพร้อมกันสำหรับธนาคารที่พร้อมก้าวข้ามการทดลองไปสู่การใช้งานจริงครับ

McKinsey ประเมินว่า generative AI จะสร้างมูลค่าสองร้อยถึงสามร้อยสี่สิบพันล้านดอลลาร์ต่อปีให้กับภาคธนาคาร คิดเป็นเก้าถึงสิบห้าเปอร์เซ็นต์ของกำไรจากการดำเนินงาน ตอนนี้ผลผลิตในฝั่ง front-office เพิ่มขึ้นเฉลี่ยยี่สิบเจ็ดถึงสามสิบห้าเปอร์เซ็นต์แล้ว โดยเฉพาะด้าน underwriting, KYC, การตรวจจับการทุจริต และบริการลูกค้าครับ

Fintech Global รายงานว่า agentic AI จะขับเคลื่อนให้ประสิทธิภาพการดำเนินงานของธนาคารเพิ่มขึ้นยี่สิบเปอร์เซ็นต์ และธนาคารที่ใช้ AI จะมีส่วนแบ่งตลาดมากกว่าสิบห้าเปอร์เซ็นต์ พื้นที่ลงทุนหลักในปีนี้ได้แก่การตรวจจับการฉ้อโกงแบบเรียลไทม์ KYC อัตโนมัติ และ voice-chat interface สำหรับลูกค้ารายย่อยครับ


หมวดที่สี่ แพลตฟอร์มข้อมูล

ที่งาน FabCon 2026 Databricks ประกาศให้ใช้งานจริงหลายผลิตภัณฑ์พร้อมกัน ทั้ง Lakebase ซึ่งเป็นฐานข้อมูลสำหรับ AI agents, Genie Code สำหรับงาน data engineering แบบ agentic และการผสานรวมใหม่กับ Excel และ Microsoft Teams นอกจากนี้ยังมี free tier ของ Lakeflow Connect เพื่อลดอุปสรรคในการ ingest ข้อมูลอีกด้วยครับ

Microsoft กับ Databricks ประกาศความร่วมมือสร้าง interoperability ระหว่าง OneLake กับ Databricks โดย Databricks จะอ่านข้อมูลจาก OneLake ได้โดยตรงแบบ public preview แล้ว และกำลังพัฒนาการเขียนข้อมูลกลับแบบสองทิศทาง นอกจากนี้ Unity Catalog ใน Microsoft Fabric ก็พร้อมใช้งานจริงแล้ว ทำให้ทั้งสองระบบแชร์ข้อมูลได้โดยไม่ต้องทำซ้ำครับ

Microsoft Fabric อัปเดตเดือนมิถุนายนนี้ยังนำ Database Hub มาให้จัดการฐานข้อมูล Microsoft แบบรวมศูนย์ และมี Fabric IQ กับ Foundry IQ สำหรับเชื่อมระบบข้อมูลที่กระจัดกระจายเข้ากับ AI workloads ได้ง่ายขึ้น รวมถึง Azure HorizonDB ที่มี vector indexing ในตัว Microsoft กำลังสร้างให้ Fabric เป็นแกนกลางสำหรับ enterprise AI ครับ


หมวดที่ห้า Microsoft AI

งาน Microsoft Build 2026 มีข่าวใหญ่สำหรับวงการ AI ครับ Anthropic Claude models เข้ามาอยู่ใน Microsoft Foundry แล้ว นอกเหนือจาก OpenAI GPT models ที่มีอยู่เดิม พร้อมกันนี้ Microsoft ยังเปิดตัว Foundry IQ, Fabric IQ, Work IQ และ Azure HorizonDB ซึ่งเป็นชุดเครื่องมือครบวงจรสำหรับสร้างและควบคุม enterprise AI agents ครับ

ธีมหลักของ Microsoft Build ปีนี้คือ data context สำคัญกว่า model power ครับ Microsoft บอกว่าโจทย์หินของ enterprise AI ไม่ใช่ตัวโมเดลอีกต่อไปแล้ว แต่คือการเชื่อมข้อมูลทางธุรกิจให้ AI เข้าถึงได้ Microsoft Fabric คือคำตอบ และ Microsoft Agent Platform คือแพลตฟอร์มครบวงจรสำหรับสร้าง รัน ควบคุม และขยาย AI agents ในองค์กรครับ

Azure ยืนยันว่า agentic AI capabilities ทั้งหมดเป็น general availability แล้ว ไม่ว่าจะเป็น computer-using agents, การสื่อสาร agent-to-agent และ real-time voice agents การเป็น GA หมายความว่าองค์กรที่อยู่ในกระบวนการจัดซื้อสามารถนำไปใช้งานจริงได้ทันทีโดยไม่ต้องรอครับ


หมวดที่หก ความปลอดภัยไซเบอร์

ข่าวน่าตกใจมากครับ Viking Cloud รายงานว่าเก้าสิบเจ็ดเปอร์เซ็นต์ขององค์กรพบปัญหาความปลอดภัยจาก GenAI ในปีสองพันยี่สิบหกนี้ เหตุการณ์ละเมิดนโยบายข้อมูล GenAI เพิ่มขึ้นมากกว่าสองเท่าเมื่อเทียบกับปีที่แล้ว โดยเฉลี่ยองค์กรหนึ่งๆ เจอเหตุการณ์นี้สองร้อยยี่สิบสามครั้งต่อเดือน บอกชัดว่าหลายองค์กรนำ AI มาใช้เร็วกว่าที่พวกเขาจะรักษาความปลอดภัยได้ครับ

งานวิจัยใหม่จาก Cloud Security Alliance พบว่า LLMs สามารถค้นหาช่องโหว่ในซอฟต์แวร์จริง สร้างโค้ดโจมตีจากรายงานช่องโหว่ และดำเนินการโจมตีเครือข่ายหลายขั้นตอนได้โดยอัตโนมัติ ซึ่งในบางสถานการณ์ทำได้ดีกว่า human red teamers ด้วยซ้ำ ช่วงเวลาระหว่างที่ค้นพบช่องโหว่กับที่ถูกโจมตีสั้นลงอย่างมากครับ

GreyNoise บันทึกการโจมตี LLM services ที่เปิดเผยสู่อินเทอร์เน็ตมากกว่าเก้าหมื่นหนึ่งพันเซสชั่นในช่วงตุลาคมสองพันยี่สิบห้าถึงมกราคมสองพันยี่สิบหก นอกจากนี้ RAG poisoning ซึ่งคือการฝังเอกสารมุ่งร้ายเข้าไปในฐานข้อมูล retrieval ก็กำลังกลายเป็น attack vector สำคัญที่ยังไม่ได้รับความสนใจเท่าที่ควรครับ

ปิดท้ายหมวดนี้ การวิจัยด้านความปลอดภัยพบว่าเทคนิค jailbreak บางตัวได้ผลมากกว่าห้าสิบเปอร์เซ็นต์กับ LLMs ชั้นนำ และบางกรณีสูงถึงแปดสิบแปดเปอร์เซ็นต์ OWASP ระบุว่า semantic attacks ซึ่งโจมตีผ่านความหมายของ prompt ไม่ใช่รูปแบบ คือภัยคุกคามที่เครื่องมือรักษาความปลอดภัยแบบดั้งเดิมรับมือไม่ได้ครับ


ห้าสิ่งที่ต้องจับตามองวันนี้

หนึ่ง ชิป Jalapeño ของ OpenAI อาจเปลี่ยนโครงสร้างต้นทุน AI compute ทั้งอุตสาหกรรม ถ้าทำได้จริงตามที่ทดสอบ

สอง สงครามราคา AI ยังไม่จบ DeepSeek ราคาถาวรและถูกกว่ามาก ทำให้ผู้ให้บริการรายอื่นต้องแข่งด้วยคุณภาพหรือลดราคาตาม

สาม Microsoft กำลังเปลี่ยน default ของ Office 365 เป็น agentic AI ซึ่งจะกระทบการทำงานของพนักงานองค์กรทั่วโลกโดยไม่รอถาม

สี่ ธนาคารที่เริ่ม agentic AI เร็วจะมีข้อได้เปรียบด้านส่วนแบ่งตลาดสิบห้าเปอร์เซ็นต์ตามที่ Fintech Global ประเมิน ช่องว่างนี้จะถ่างขึ้นเรื่อยๆ

ห้า ความปลอดภัยไซเบอร์กำลังล้าหลังการนำ AI มาใช้อย่างมีนัยสำคัญ องค์กรที่ยังไม่มีนโยบาย AI security ชัดเจนกำลังเสี่ยงอยู่ครับ


ขอบคุณที่รับฟัง MorningInsight ครับ มีวันที่ดีและขับรถปลอดภัยนะครับ พบกันพรุ่งนี้เช้า
